# GO 目录

本目录包含 Go 语言的学习和实践代码，主要演示 Go 语言的基础语法、并发编程、网络编程等内容。

## 主要文件

### hello.go
- **用途**：Go 语言基础示例
- **内容**：简单的 "Hello, World!" 程序

### CGO.go
- **用途**：CGO 编程示例
- **内容**：演示 Go 语言如何调用 C 语言代码

### CGO-SayHello.go
- **用途**：CGO 函数调用示例
- **内容**：演示 Go 与 C 语言函数互调

### Channels.go
- **用途**：Go 通道（Channels）示例
- **内容**：演示 Go 语言的并发通信机制

### GoSelect.go
- **用途**：Select 语句示例
- **内容**：演示如何使用 select 语句处理多个通道

### strings_splitjoin.go
- **用途**：字符串处理示例
- **内容**：演示字符串的分割和拼接操作

### Web-echo.go
- **用途**：Web 服务器示例
- **内容**：使用 echo 框架创建简单的 Web 服务
