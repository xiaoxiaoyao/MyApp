# JAVA 目录

本目录包含 Java 语言的学习和实践代码，涵盖了 Java 基础、面向对象编程、Web 开发等内容。

## 子目录说明

### helloworld
- **用途**：Java 基础入门示例
- **内容**：最简单的 Java 程序，演示 "Hello, World!"
- **技术栈**：Maven、Java SE

### spring_hello_world_demo
- **用途**：Spring Boot 入门示例
- **内容**：使用 Spring Boot 框架的简单 Web 应用
- **技术栈**：Spring Boot、Maven、RESTful API

### JavaProject
- **用途**：Java 高级特性学习
- **内容**：包含多线程编程、集合框架、反射等高级特性示例
- **主要文件**：
  - PeopleInterface.java - 接口定义
  - PeopleChinese.java - 接口实现
  - MutithreadLearningRunnable.java - 多线程示例
  - HashMap1.java - 集合框架示例

### demo
- **用途**：Java 技术演示代码
- **内容**：各种 Java 技术的演示和学习代码

### packages
- **用途**：Java 包管理示例
- **内容**：包含第三方库和工具的使用示例
