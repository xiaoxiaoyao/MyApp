# PythonApplication1 目录

本目录包含 Python 应用程序的学习和实践代码，涵盖了多个领域的 Python 编程示例。

## 子目录说明

### 爬虫练习
- **用途**：网络爬虫学习和实践代码
- **内容**：包含使用 requests、beautifulsoup 等库的爬虫示例
- **子目录**：
  - JD：京东网站爬虫示例
  - toutiao：今日头条网站爬虫示例
  - FIREFOX：Firefox 浏览器自动化示例

### my_first_web_app
- **用途**：Web 应用开发示例
- **内容**：基于 Flask/Django 等框架的 Web 应用
- **子目录**：
  - test：测试文件和配置
  - www：Web 应用主体代码

### 自己的小练习
- **用途**：Python 基础语法和算法练习
- **内容**：包含各种 Python 编程练习题的解答
- **子目录**：
  - JD小组开发：JD 项目相关代码
  - HLS：数据分析和处理代码

### deeplearning
- **用途**：深度学习学习和实践代码
- **内容**：使用 TensorFlow、PyTorch 等框架的深度学习示例
- **子目录**：
  - examples：通用深度学习示例
  - tools：深度学习工具代码
  - JDdata：JD 项目数据分析

## 主要技术栈
- Python 3.x
- 网络爬虫：requests、beautifulsoup4
- Web 开发：Flask、Django
- 数据分析：pandas、numpy
- 深度学习：TensorFlow、PyTorch

- 深度学习资源：https://tensorflow.org/
