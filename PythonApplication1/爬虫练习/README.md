# 爬虫练习目录

本目录包含网络爬虫的练习项目和代码。

## 主要子目录

- `chromedriver` - 使用 ChromeDriver 的爬虫项目
- `FIREFOX` - 使用 Firefox 的爬虫项目
- `JD` - 京东网站爬虫
- `toutiao` - 今日头条爬虫

## 主要文件

- `IpProxy1.py` - IP 代理相关代码

## 依赖

确保已安装相关依赖：

```bash
pip install selenium requests beautifulsoup4
```

同时需要下载对应的浏览器驱动（ChromeDriver 或 GeckoDriver）。
