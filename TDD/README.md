# TDD 目录

本目录包含测试驱动开发（Test-Driven Development）的学习和实践代码。

## 子目录说明

### python_unittest
- **用途**：Python 单元测试示例代码
- **内容**：包含 mathfunc.py 数学运算函数和对应的单元测试
- **主要文件**：mathfunc.py - 数学运算函数实现

### UnitTestDrivenDevelopment
- **用途**：单元测试驱动开发的示例代码
- **内容**：包含 C++ 测试代码和示例项目
- **主要文件**：testgcd.cpp - 最大公约数测试

## 学习资源
- Python 官方文档：https://docs.python.org/3/library/unittest.html
- C++ 测试框架：Google Test, Catch2 等
