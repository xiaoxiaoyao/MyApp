# TDD 目录

本目录包含测试驱动开发（Test-Driven Development, TDD）的相关示例和练习。

## 主要子目录

- `python_unittest` - Python 单元测试示例
- `UnitTestDrivenDevelopment` - 单元测试驱动开发项目

## Python 单元测试

使用 Python 内置的 `unittest` 框架进行单元测试。

## 运行测试

对于 Python 单元测试：

```bash
cd python_unittest
python -m unittest test_mathfunc.py
```

或者直接运行测试文件：

```bash
python test_mathfunc.py
```
