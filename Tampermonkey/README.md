# Tampermonkey 用户脚本目录

本目录包含用于 Tampermonkey 浏览器扩展的用户脚本。

## 主要脚本

- `SaveTableAsCSV.user.js` - 将网页表格保存为 CSV 文件的脚本
- `JD-auto-checkIn.user.js` - 京东自动签到脚本
- `屏蔽知乎热门内容推荐.user.js` - 屏蔽知乎热门内容推荐的脚本

## 安装说明

1. 确保浏览器已安装 Tampermonkey 扩展
2. 点击脚本文件，Tampermonkey 会自动提示安装
3. 或者在 Tampermonkey 管理面板中手动导入脚本

## 使用说明

安装后脚本会在对应的网站自动运行。
