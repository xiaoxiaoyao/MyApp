# VBA 模块目录

本目录包含 Excel VBA 宏模块，用于自动化处理 Excel 数据和报表生成。

## 文件列表

### 1. Excel-VBA-批量将多个sheet表另存.bas
- **功能**: 将当前选中的所有工作表分别另存为独立的 Excel 文件
- **主要过程**: `SaveSheetAsWorkbook()`
- **使用场景**: 需要将工作簿中的多个工作表拆分成单独的文件
- **输出格式**: Excel 97-2003 格式 (.xls)

### 2. Excel-VBA-筛选后单独存SHEET.bas
- **功能**: 根据供应商列表筛选数据并生成结算单
- **主要过程**:
  - `A3_filters()`: 主处理过程，为每个供应商生成结算单
  - `SaveSheetAsWorkbook()`: 辅助过程，保存工作表
- **前置条件**:
  - 需要 "CP_sheet" 工作表（供应商列表）
  - 需要 "CP_0" 工作表（原始数据）
  - 需要 "template" 工作表（结算单模板）
- **使用场景**: 财务结算、按客户生成独立报表

### 3. Excel-VBA-创建数据透视表.bas
- **功能**: 从原始数据创建数据透视表
- **主要过程**: `A1_NewPivotSets()`
- **数据透视表配置**:
  - 行字段: 日期、版本、供应商
  - 数据字段: 收入额（结算金额求和）、结算分成（结算分成额求和）
  - 显示方式: 表格形式，重复显示标签
- **使用场景**: 数据汇总分析、财务报表生成

### 4. Excel-VBA-CopySheets.bas
- **功能**: 复制数据透视表内容并去除格式
- **主要过程**: `A2_NewSheet()`
- **处理流程**:
  1. 复制 A:E 列数据
  2. 创建新工作表 "CP_0"
  3. 粘贴为值和数字格式（去除透视表格式）
  4. 删除表头行
- **使用场景**: 数据透视表数据导出、格式转换

## 使用说明

### 导入 VBA 模块
1. 打开 Excel，按 `Alt + F11` 进入 VBA 编辑器
2. 在左侧项目窗口中右键点击 "VBAProject"
3. 选择 "导入文件"，选择对应的 .bas 文件
4. 模块将自动导入并可以在宏中使用

### 运行宏
1. 按 `Alt + F8` 打开宏对话框
2. 选择要运行的宏名称
3. 点击 "运行"

### 注意事项
- 运行宏前请确保已保存工作簿
- 部分宏会修改工作表结构，建议先备份数据
- 确保工作簿中包含宏所需的工作表（如 CP_sheet、template 等）

## 代码规范

所有 VBA 代码均遵循以下规范：
- 模块头部包含功能描述、作者、日期、版本信息
- 每个过程都有详细的注释说明
- 变量声明使用 `Dim` 语句并注明用途
- 关键代码行都有中文注释
- 使用错误处理机制（On Error GoTo）
