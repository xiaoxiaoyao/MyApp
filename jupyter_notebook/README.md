# Jupyter Notebook 目录

本目录包含 Jupyter Notebook 项目，用于数据分析、机器学习和深度学习实验。

## 主要子目录

- `statistical` - 统计学相关的 Notebook
- `Titanic` - 泰坦尼克号数据集分析
- `深度有趣` - 深度学习项目和示例

## 主要项目

### 深度有趣

包含多个深度学习实战项目：

- `04图像风格迁移` - 使用 TensorFlow 和 Keras 实现图像风格迁移
- `05自编码器图像去噪` - 使用自编码器进行图像去噪
- `06变分自编码器` - 变分自编码器实现
- `DCGAN 手写数字生成` - 使用 DCGAN 生成手写数字

## 运行说明

确保已安装 Jupyter Notebook 和相关依赖：

```bash
pip install jupyter numpy pandas matplotlib tensorflow keras
```

启动 Jupyter Notebook：

```bash
jupyter notebook
```
